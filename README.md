# Take care Sis

A gentle, low-stimulation wellness companion browser extension designed to protect your physical and mental well-being during the hectic workday. 

Built using modern Chrome Manifest V3, this extension runs seamlessly in the background and opens an immersive, soothing screen every 45 minutes to encourage a quick wellness break.

---

## Features

* **Custom Routine Selection:** Toggle specific wellness check-ins on or off (Water, Breathing, Stretch, Gratitude, and Kegels).
* **Smart Session Memory:** Remembers your unique preferences between sessions using local storage cache mechanics.
* **Interactive Timelines:** A responsive, fluid scaling ring to guide your box-breathing and customized pelvic floor pacing.
* **Randomized Active Stretches:** Cycles through a localized pool of fitness animations to keep your movement breaks fresh and engaging.
* **Privacy-First Architecture:** Runs 100% locally on your machine with zero external trackers, analytics, or remote script injections.

## Installation and Local Development

To run this project locally in developer mode:

1. **Clone the repository:**
   git clone https://github.com/YOUR_USERNAME/take-care-sis.git

2. Open Google Chrome and navigate to `chrome://extensions/`.
3. In the top-right corner, switch **Developer mode** to **ON**.
4. In the top-left corner, click **Load unpacked**.
5. Select the root `take-care-sis` project directory.
6. Pin the extension to your toolbar, customize your selections, and click **Start Workday**!
